TelegramCloud — Info & Capabilities
Unlimited Cloud Storage Infrastructure

TelegramCloud converts your private Telegram Channel into an encrypted, high-performance cloud drive with unlimited capacity, fast upload/download streams, and automated sync tools.

AES-256 Binary Encryption

Files are encrypted before transmission using industry-standard cryptography, guaranteeing privacy for stored documents, media, and archives.

Large File Chunking (>19.5MB)

Files exceeding Telegram limits are seamlessly split into 19.5MB parts, uploaded concurrently with progress reporting, and automatically reassembled upon download or preview.

Auto-Sync & Backup

Sync changes directly with Telegram channel updates (`/sync`) and persist catalog metadata backups (`/backup`) safely inside Telegram storage.

Mobile Web App Ready

Optimized PWA interface with fixed bottom navigation, touch action cards, quick-upload floating action button, and touch gesture support.

Telegram Bot Commands
Command Description
/storage Returns live storage stats (total files, folders, consumed space).
/search <filename> Searches files matching name query in Telegram catalog.
/backup Backs up entire `schema.json` to the Telegram storage channel.
/sync Scans Telegram channel messages and synchronizes local catalog.
💡 Pro Tip: Drag and drop multiple files anywhere in the dropzone for live NDJSON upload progress tracking!
